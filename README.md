# Expense Tracker (Ledger)

Split expenses with friends: groups, even splits, running balances, settlements,
invite links, and a React frontend.

## Stack

- **API:** ASP.NET Core 8, EF Core + SQLite, JWT auth
- **Web:** React + Vite + TypeScript

## Run locally

### 1. API

```bash
cd ExpenseTracker.Api
dotnet restore
dotnet run
```

Listens on `http://localhost:5000` by default. Swagger: `http://localhost:5000/swagger`.

### 2. Frontend

```bash
cd expense-tracker-web
npm install
cp .env.example .env   # optional — defaults to localhost:5000
npm run dev
```

Open `http://localhost:5173`.

## Features

| Feature | How |
|---|---|
| **Invite by link** | Members tab → copy invite link → share `/join/{code}` |
| **Invite by email** | Members tab → enter email → “Open in email app” (mailto with link) |
| **Join via link** | Visit `/join/{code}`, log in or register, auto-join |
| **Leave group** | Members tab → “Leave group” |
| **Add payments** | Payments tab → record who paid whom + see history |
| **Add expenses** | Add expense tab → split across members |

## API highlights

### Invites

| Method | Route | Notes |
|---|---|---|
| GET | `/api/invites/{code}` | Preview group (no auth) |
| POST | `/api/invites/{code}/join` | Join group (auth required) |
| GET | `/api/groups/{id}/invite-link` | Get shareable link |
| POST | `/api/groups/{id}/invites/email` | `{ "email" }` — tracks invite + returns link |
| DELETE | `/api/groups/{id}/members/me` | Leave group |

See Swagger for auth, expenses, settlements, and the rest.

## Deploy online (free tier)

**Frontend → Vercel**, **API → Render** (Vercel doesn’t host .NET APIs).

### Deploy the API on Render

1. Push this repo to GitHub.
2. [Render](https://render.com) → **New Blueprint** → connect repo (uses `render.yaml`).
3. After deploy, note the API URL (e.g. `https://expense-tracker-api.onrender.com`).
4. In Render dashboard → Environment, add your Vercel URL to CORS:
   - Set `Cors__AllowedOrigins__0` = `https://your-app.vercel.app`
5. `JWT_KEY` is auto-generated by the blueprint.

SQLite lives on a persistent 1 GB disk (`/data/expensetracker.db`).

### Deploy the frontend on Vercel

1. [Vercel](https://vercel.com) → **Import** repo.
2. Set **Root Directory** to `expense-tracker-web`.
3. Add environment variable:
   - `VITE_API_URL` = `https://YOUR-RENDER-API.onrender.com/api`
4. Deploy. `vercel.json` handles SPA routing for `/join/:code`.

### After both are live

Update Render CORS with your real Vercel URL, redeploy the API if needed, then
test: register → create group → copy invite link → open in incognito → join.

## Example flow (curl)

```bash
BASE=http://localhost:5000

curl -s -X POST $BASE/api/auth/register -H "Content-Type: application/json" \
  -d '{"name":"Jace","email":"jace@test.com","password":"password1"}'
# use token from response

TOKEN="<token>"

curl -s -X POST $BASE/api/groups -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" -d '{"name":"Weekend trip"}'

curl -s $BASE/api/groups/1/invite-link -H "Authorization: Bearer $TOKEN"

curl -s -X POST $BASE/api/groups/1/expenses -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"description":"Dinner","amount":120,"paidByUserId":1,"category":"Food"}'

curl -s -X POST $BASE/api/groups/1/settlements -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"fromUserId":2,"toUserId":1,"amount":30}'
```

## Notes

- Replace the dev JWT key (`appsettings.json`) or use `JWT_KEY` env var in production.
- `EnsureCreated` + lightweight schema updater handles new columns/tables locally.
  For a larger app, switch to EF migrations.
- Email invites generate a shareable link; the app does not send email itself (no SMTP).
